## 1. 审计范围及方法

**已审范围**：Vue 3 / TypeScript / OpenLayers 前端；公开影像目录、WMS / WMTS/XYZ 瓦片加载；点线面几何编辑、属性编辑、地理量算、空间检索、GeoJSON 导入导出、本地草稿；移动端适配；GitHub Actions 类型检查、安全审计、构建、Pages 部署、在线资源检查、Chromium 端到端测试。

**没有纳入**：尚未实现的 FastAPI 后端、PostGIS、真实登录、用户 RBAC、业务审批、GeoTIFF 私有上传与转 COG、内网部署/备份、安全等级保护。它们不是本轮「已实现功能」的缺陷修复目标，不得据此声称已有正式生产能力。

## 4. 依赖安全审计与残余告警

- `npm audit --omit=dev --audit-level=high`：**0 vulnerabilities**。
- `npm audit --audit-level=high`：仍检测到一个**低严重度**的开发依赖 `esbuild@0.27.7` 公告 [GHSA-g7r4-m6w7-qqqr](https://github.com/advisories/GHSA-g7r4-m6w7-qqqr)，涉及直接使用 esbuild Windows 开发服务提供静态文件的特定情况；当前 GISTable 不直接调用 esbuild 的 `serve` API。未强制将 Vite 的 esbuild 依赖跨小版本覆盖到不符合其依赖范围的版本，以免制造构建兼容性问题，后续随 Vite 支持的依赖版本统一升级。
- 开发入口从 `vite --host 0.0.0.0` 改为 `vite`（默认本机监听）；确需在可信局域网共享访问时应明确执行 `npm run dev:lan`，不得暴露到公网。
- 建议定期复查所有依赖和 Actions 版本，合并更新前执行完整回归。

## 5. 未覆盖与交付前保留事项

1. **浏览器覆盖**：自动化测试为 GitHub Ubuntu Runner 上的 Chromium，尚未完整验证 Firefox、Safari、Windows Edge 和触屏多点手势。
2. **空间专业精度**：距离/面积目前为 OpenLayers 球面量算；严肃公路桩号、控制区及执法取证需要当地坐标转换、测绘精度和规范化检验。
3. **GeoJSON 限制**：当前导入采用 RFC 7946 WGS84 经纬度子集，最大单文件 8MB、整个工作区 5000 个标注和单次导入 30000 个坐标位置；复杂 GIS 数据需独立处理流程。
4. **本机存储**：草稿数据仅在浏览器 localStorage，容量有限、用户清理浏览器数据后可能消失、不具备多用户审计和正式数据保存能力，需保留并提醒导出文件。
5. **第三方影像**：公共 EOX/NASA 图层仅供合规影像浏览展示，须保留署名，可能限速、失败或受地区网络影响，不代表能够识别违法建筑。不得据此承诺正式 SLA。
6. **完整数据处理和业务系统**：真实 GeoTIFF/COG 处理、上传、后台空间服务、正式用户/组织权限和巡查业务流程需要在后续阶段与后端共同验证。
7. **压力测试**：尚未在 1–2TB 数据量或多用户并发下开展容量与性能测试；不得据本轮前端测试推断正式服务器所需资源。
8. **静态平台**：GitHub Pages 无正式身份鉴权能力；禁止上传未授权影像及真实敏感执法数据，生产部署须另设有服务端鉴权的系统。
